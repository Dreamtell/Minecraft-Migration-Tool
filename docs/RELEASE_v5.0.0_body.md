### 🚀 v5.0.0 — 迁移这件事，从头到尾都能看见、能后悔

这版的重点是**把"迁移"做成一件能放心的事**：迁移前先体检，迁移中看得见进度，
迁移后能回看档案，做错了能按类别回滚，界面还能整体切英文。

### ✨ 新增

- **迁移档案**：每迁移一次记一条档案（源、目标、逐项统计、完整日志），历史窗口左侧卡片、右侧详情。
- **按类别回滚**：每次迁移各留一份备份（`<目标>/.migrate_backup/rec_<档案id>/`，保留最近 5 份）；
  回滚时可以只还原模组 / 配置 / 存档 / 根目录文件 / 「其它文件」清单里的任意几类。
- **应用到主界面**：从历史里挑一条档案，一键把当时的路径和三个清单填回主界面；填错了能一键还原。
- **联网搜索模组**：Modrinth + CurseForge 双来源，合并成一张表，标注来源、作者、下载量、
  最新版本；★ 标出各平台各自最相似的那条，一键打开项目页或下载页。
- **界面语言**：中文 / English 一键切换（切换后自动重启），带国旗标识；全文案覆盖到设置、对话框、日志。
- **按钮可配置**：设置里能勾选显示/隐藏任意操作按钮并上下调整顺序，主界面立即生效。
- **按钮音效**：悬停 / 按下各一声（素材来自 Pixabay，CC 可商用，随包分发；可在设置里关掉或试听）。

### 🎨 改进

- **每个动作都有回音**：模拟运行、覆盖策略、主题切换、滚动速度、历史条数……以前按了没反应的地方都补了提示；
  吐司点开会进**消息中心**（状态栏铃铛），淡掉之后也能回看。
- **迁移中进度条**：三档手感（干脆 / 标准 / 沉）、倒计时沙漏、底部进度条按真实耗时推进，
  并且在 144Hz 屏上按刷新率走；进度窗之前一直退回浅色主题，这版修好了。
- **放大查看**：单独的子进程窗口，几万条也流畅；关窗不再等后台扫完（原来最多卡 1.5 秒）。
- **输入框聚焦**：从"圈里套一个小光环"改成整圈呼吸光边，60fps、每帧 0.47ms，没有任何锯齿。
- **启动**：主界面不再先白一下（把窗口类的背景刷子换成了主题色），同时保留 Windows 自带的窗口打开动画。
- **设置页**：短页面不再"抽搐"（内容装得下就不接滚轮）；滑条不再被滚轮误触。

### 🔧 修复

- 添加模组时把绝对路径写进清单，导致同一模组出现两条、自检又说"源里没有" —— 现在统一只存文件名并按名字去重，旧清单启动时自动整理。
- 模拟运行的档案一直是 `None.json`，每次覆盖同一份 —— 已修，历史里那份会被自动改名。
- 「拖放不可用」的假警报（拖放其实是好的，只是提示没刷新）。
- 深浅主题下多处自绘控件（工具栏尾按钮、分段选择）切英文后仍是中文。
- 列表被压到 37px、日志框高度不受控、说明行不换行被挤成一条。

### 🩺 诊断

- 主线程卡住超过 0.4 秒会自动把堆栈写进 `~/.minecraft_migrate_hang.log`；
  启动日志里现在还会写明「拖放已就绪（tkinterdnd2 x.y.z）」，出问题截图就能定位。

### ⚠️ 升级注意

- 旧配置、旧清单、旧目录可以直接沿用；旧清单里带绝对路径的条目会在载入时自动整理成文件名。
- **本包是 onedir 打包：解压后 `app.exe` 必须和 `_internal/` 目录放在一起**，只拷 exe 打不开。
- 没有代码签名：首次运行 Windows 会弹"已保护你的电脑"，点「更多信息 → 仍要运行」。
- 迁移到 `C:\minecraft\...` 这类受保护目录时，程序会提示「以管理员身份重启」。
- 旧版的单一备份目录会在下次迁移成功后自动清理，只保留按档案分的备份。

### 🐞 已知问题

- 「扫描差异」只能比出文件名和版本的不同，**作者删掉或替换掉的模组是发现不了的**，请对照更新日志。
- 本工具不提供任何模组下载，缺失的模组请用 PCL 等启动器补装。
- CurseForge 搜索需要自己在设置里填 API Key（工具不内置任何 Key，也不会上传）。
