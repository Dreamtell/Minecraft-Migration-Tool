## 一、发布说明怎么写（五段式）

一段好的 Release 说明，按这个顺序写就不会乱：

1. **一句话主题** —— 这版主要是为了解决什么。比如这版是「让每一次操作都有回音」。读者只读这一句也能知道该不该升级。
   - ❌ 别写「修复若干问题，优化用户体验」——等于什么都没说。
   - ✅ 别写 commit 术语（`refactor toast tick loop`），写用户看得见的现象。
2. **分流亮点** —— 分「新增 / 改进 / 修复」三组，每组 3-6 条，**一条只讲一件事**，并且写成「做了什么 + 对你有什么好处」。
   - ❌ 「优化吐司渲染管线」
   - ✅ 「吐司圆角现在是抗锯齿的平滑边，深色主题下不再露出底色块」
3. **升级注意** —— 旧配置/旧清单/旧目录能不能直接用，需不需要重新选一次路径，运行环境有没有变（这版要求 Windows 10+、Python 不需要装因为 exe 自带）。
4. **已知问题** —— 诚实列出来。下载用户最反感的是「装完发现某个功能坏了而且没人提过」。
5. **下载与校验** —— 文件名、SHA256（用仓库里的 `哈希计算.bat` 生成）、系统要求。

三条原则：**用现象代替术语**、**数字要具体**（`95ms → 5ms` 比「大幅提速」可信）、**不吹**（没验证过的别写"已修复"）。

## 二、v5.0.0 正文（复制这一段）

### 🚀 v5.0.0 — 每一次操作都要有回音

这版的主线是**通知系统**：以前大量操作（模拟运行、覆盖策略、边缘特效、滚动速度、主题切换……）都是静默的，你点完不知道有没有生效；现在每一次操作都会在右下角说一句"我刚才做了什么"，并且能在**消息中心**里回看。

### ✨ 新增

- **消息中心**：状态栏右侧铃铛 + 未读徽标，点铃铛或按 `Ctrl+M` 从右边滑出一张抽屉，吐司淡掉之后也能回看历史消息。
- **消息行卡**：一条消息一张卡，等级图标 + 文案 + 时间 + 等级文字（成功 / 警告 / 错误）。
- **重复合并**：同一秒里反复拨同一个开关会合并成一条并标 `×N`，不会刷满一屏。
- **四种等级的操作反馈**：成功 / 提示 / 警告 / 错误，配左侧等级条和底部进度条；错误类默认常驻，点卡片即可关掉。

### 🎨 改进

- **操作反馈补齐**：模拟运行开关、覆盖策略、边缘特效、整合包更新警告、滚动速度、历史条数上限、主题切换等静默操作，现在都有提示。
- **吐司更好看**：整体放大 1.3 倍（字号 15px，短消息 292×75），长消息按屏宽封顶并自动截断，中文与 emoji 混排不再出方块。
- **吐司真透明**：改用逐像素透明渲染，圆角是抗锯齿的平滑边，深色主题下不再露出底色块，也没有像素台阶。
- **动画跟刷新率走**：高刷屏上明显更顺；进度条按 1/8 像素推进，边缘是真的在移动。
- **换主题不再卡顿**：圆角矩形按尺寸/颜色缓存，重画一组卡片从 95ms 降到 5ms。

### 🔧 修复

- 修复深色主题下吐司圆角"看不见"、以及吐司窗口带一条灰色底边的问题。
- 修复新消息出现时旧卡片位置抖动的问题。
- 修复窗口最小化后悬浮条没有跟随隐藏的问题。
- 修复设置页、清单操作、页面切换等多处完全没有提示的问题。

### 🩺 诊断

- 新增卡顿定位：界面连续无响应时自动抓主线程堆栈写进 `~/.minecraft_migrate_hang.log`，出问题把这两文件发出来就能定位到具体哪一行。

### ⚠️ 升级注意

- 旧配置、旧清单、旧目录可以直接沿用，不需要重新配置。
- exe 自带 Python 与 Qt，下载即用；Windows 10 及以上。
- 首次启动会问一次语言，之后记住选择。

### 🐞 已知问题

- 高 DPI 缩放（如 150%）下，部分老皮肤的进度条边缘仍有 1 像素偏差。

## 三、打包与产物

```bat
rem 仓库根目录，不注入内置 API Key（对外发布必须如此）
打包_命令行.bat nopause
```

- 构建脚本顶部注释里写清了三条约束：`--onedir` 的原因、`--paths _qt` 的原因、以及**发布版不能带内置 CurseForge Key**。
