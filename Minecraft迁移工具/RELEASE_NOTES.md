# 🚀 v5.0.0

Minecraft 存档迁移工具（迁移工坊）v5.0 正式发布！

本版本的主线是 **「每一次操作都要有回音，而且看得清」**：把所有散落的操作反馈收成一套通知系统 —— 右下角的**吐司**（toast）负责即时提醒，状态栏铃铛背后的**消息中心抽屉**负责回看。顺便把这套东西的绘制方式和动画开销压到跟着显示器刷新率跑。

> ✅ 完全免费 · 开源 · 纯中文界面 · 单文件可执行

---

## ✨ 新增功能

### 🔔 消息中心（全新）
- 状态栏右侧新增 **铃铛 + 未读徽标**，点铃铛或按 `Ctrl+M` 从右边滑出一张抽屉。
- 消息一条一张行卡：等级图标 + 文案 + 时间 + 等级文字（成功 / 警告 / 错误）。
- **同一个开关反复拨动会合并成一条**并标 `×N`，不会刷满一屏。
- 抽屉是无边框的圆角卡片，**滑入、滑出的每一帧都保持圆角**：窗口区域随动画展阔，内容不跟着平移。
- 关闭方式：✕ / `Esc` / 再点一次铃铛 / 主窗口最小化时自动收回。

### 💬 操作反馈（吐司）
- 补齐全部**静默操作**：模拟运行开关、覆盖策略、边缘特效、整合包更新警告、滚动速度、历史条数上限、主题切换……都会说一句"我刚才做了什么"。
- 吐司支持 **成功 / 提示 / 警告 / 错误** 四种等级，左侧等级条 + 底部进度条；错误类默认常驻，点卡片即可关掉。
- 卡片整体放大 1.3 倍，字号 15px，短消息 292×75，长消息按屏宽封顶并自动截断。
- **中文与 emoji 混排**：表情用彩色字形字体绘制，不会变成方块。
- 带 `key` 的消息**原地更新**而不是再弹一条；文案完全相同的自动合并。

## ⚡ 体验与性能
- 吐司改用 **逐像素透明**（PIL 合成 + `UpdateLayeredWindow`）：圆角是抗锯齿的平滑边，不再有假透明漏出的底色块，也没有像素台阶。
- 动画**跟着显示器刷新率走**（动画期间临时提高定时器精度，并按每帧实际耗时扣减间隔），高刷屏上明显更顺；进度条按 1/8 像素推进，边缘是真的在移动。
- 退场只淡出不横穿窗口边界，多条堆叠时不会再出现"插队"的观感。
- **换主题不再卡顿**：圆角矩形按尺寸/颜色缓存、小尺寸才用 4× 超采样，重画一组卡片从 95ms 降到 5ms。

## 🩺 诊断
- 新增 `utils/hangwatch.py`：界面连续无响应时抓主线程堆栈写进 `~/.minecraft_migrate_hang.log`，卡顿能定位到具体哪一行。

## 🔧 修复
- 修复设置页、模组清单、页面切换等多处操作完全没有提示的问题。
- 修复深色主题下吐司圆角"看不见"、以及吐司窗口带一条灰色底边的问题。
- 修复新消息出现时旧卡片位置抖动的问题。
- 修复窗口最小化后悬浮条没有跟随隐藏的问题。

# 🚀 v4.0.0

Minecraft 存档迁移工具（迁移工坊）v4.0 正式发布！

本版本聚焦 **体验与性能**：新增迁移前磁盘空间检查、存档实时检测、Modrinth 联网搜同款模组、全窗口渐变按钮，并针对大列表做了明显提速。

> ✅ 完全免费 · 开源 · 纯中文界面 · 单文件可执行

---

## ✨ 新增功能

### 💾 更安全的迁移
- **迁移前磁盘空间检查**：自动校验目标磁盘能否容纳「迁移数据 + 目标备份」，空间不足时在迁移前拦截提示，避免复制中途失败。
- **存档实时检测**：输入存档名即实时显示该存档在源目录下是否存在（✅ / ❌），不再需要手动点“检查”按钮。

### 🔍 联网搜同款模组
- 模组详情窗口新增 **Modrinth 联网搜索**（免费、无需密钥）。
- **最相似匹配**：自动把本地模组与线上最相似项目匹配并置顶。
- 展示最新版本、下载量，支持复制/打开项目与下载链接。
- 只读搜索，不修改本地文件；离线时核心迁移不受影响。

### 🎨 界面全面统一
- **全窗口渐变按钮**：主界面、放大查看、模组详情、差异窗口的所有按钮统一为渐变色，配色语义清晰。
- 按钮文字、禁用、回调等行为与普通按钮完全兼容。

### 📁 清单管理 & 放大查看增强
- 新添加的模组自动 **黄色高亮** 提示。
- 放大查看随主界面清单外部变更 **自动刷新**。
- 搜索输入加入 **防抖**，避免打字卡顿。
- **清单存在性检查**：主界面「检查清单模组是否存在（源目录）」与「检查 config 是否存在（源目录）」逐行按状态高亮（存在=绿、缺失=红、重复=黄），高亮约 1 秒后自动恢复为普通文本；编辑清单会自动清除过期高亮。
- **config 文件夹显示**：主界面 config 清单按源目录自动识别目录条目并在末尾加 `/`（如 `ae2/`），与文件条目一眼区分；源路径变化、检查时自动补全。
- **放大查看悬停提示**：鼠标悬停在大窗口列表过长/被截断的单元格（如完整路径、文件名）上时，自动弹出完整内容提示。
- **执行日志放大查看**：执行日志区新增「📂 放大查看」，打开只读大窗口实时跟随日志并屏幕居中（保留 INFO/警告/错误/成功/模拟配色）。日志新增/清空时**事件驱动即时同步**，无需轮询或手动刷新；日志配色随主题自动切换，深色/浅色下都清晰可读。
- **主题全局同步**：切换浅色/深色主题时，已打开的「放大查看」窗口（模组/Config/执行日志）与差异窗口统一重新配色，背景/文字/输入框/日志色都跟随主题。

### ⚡ 大列表性能优化
- 扫描改为 **有界线程池**（固定并发），避免上万条目时线程爆炸。
- UI 更新 **分批处理** + 位置 **O(1) 索引**，上千条目不卡顿。

---

## 🐛 修复

- 修复渐变按钮动态改文字 / 禁用 / 换回调时不兼容的问题（新增 `set_text` / `state` / `set_command`）。
- 修复差异窗口排序、全选、双击详情等交互问题。
- 修复存档名称实时检测、路径区按钮样式等细节。
- **精简日志**：迁移时不再逐条记录存档/配置目录下的每一个文件（进度窗口已显示），日志只保留关键步骤、汇总与错误；连续重复提示自动去重；日志文件超过 2MB 自动轮转。
