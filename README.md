```bash
pip install pygame tendo
```

> **注意**：`pygame` 仅用于启动动画，若无需启动动画可移除相关代码。

## 🚀 快速开始

1. **选择源实例根目录**（旧版整合包）
2. **选择目标实例根目录**（新版整合包）
3. **填写存档名称**（要迁移的存档文件夹名）
4. **编辑模组清单**（每行一个 `.jar` 文件名）
5. **编辑 Config 清单**（每行一个相对路径）
6. 点击 **🚀 开始迁移**

## 🎨 界面预览

- **顶部**：主题切换按钮 + 免费声明横幅
- **路径选择**：源目录 / 目标目录（带实时验证）
- **存档名称**：输入 + 检查按钮（绿/红状态）
- **模组清单**：可编辑文本区 + 扫描差异 + 放大查看
- **Config 清单**：可编辑文本区 + 导入/浏览
- **操作按钮**：模拟运行 / 覆盖选项 / 开始迁移（渐变绿）/ 回滚 / 查看历史
- **日志区域**：实时日志 + 清空 + 打开文件夹

## 🔧 主要功能

### 迁移功能
- 复制模组（按清单）
- 复制 `options.txt`
- 复制存档（递归）
- 复制 Config 文件/文件夹（递归）

### 辅助功能
- 模组差异扫描（元数据级匹配）
- 备份与回滚
- 迁移历史记录
- 模拟运行
- 主题切换（浅色/深色）
