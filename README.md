Minecraft 整合包迁移工具 v5.1

一款用于将旧版整合包的模组、配置、存档迁移到新版整合包的工具。

功能亮点：
- 智能模组差异扫描（支持 Forge / Fabric 模组元数据识别）
- 迁移前自动备份，支持一键回滚
- 真实进度显示，支持取消
- 迁移历史记录
- 深色/浅色主题
- 单例运行，防误关保护

使用说明：
1. 选择旧版整合包实例目录（源）
2. 选择新版整合包实例目录（目标）
3. 点击“扫描模组差异”勾选要迁移的模组
4. 点击“开始迁移”

安全提示：
- 迁移前会自动备份目标实例的 mods、config、saves 文件夹
- 如遇杀毒软件误报，请添加白名单
